The full Phase 23 frontend surface is wired up: api.ts and hooks.ts now mirror every backend endpoint introduced in plans 23-03/04/05, three new components (NotesEditor, FilesPanel, plus the rewritten CardDetailModal) compose them into the existing card-detail UX. Plan 23-07 layers the notification dot, archive dialog, and isolation regression test on top.

## What Was Built

- **`frontend/package.json`** (commit `1672e9b`) — added `react-markdown ^10.1.0` and `rehype-sanitize ^6.0.0`. `@radix-ui/react-tabs` was already installed (NotesEditor consumes it via the existing `components/ui/tabs.tsx` shadcn wrapper).
- **`boardApi`** (commit `1672e9b`) — seven new methods (`updateNotes`, `downloadFile` returning `Blob`, `editComment`, `softDeleteComment`, `archiveCard`, `getUnreadNotificationCount`, `markCardNotificationsRead`); `addComment` extended with optional `mentions: string[]`. Existing `deleteComment` preserved as a deprecated alias of `softDeleteComment` so any callers not yet migrated still resolve.
- **`types.ts`** (commit `1672e9b`) — `BoardCard.notesUpdatedAt/notesUpdatedBy`, `BoardComment.{isDeleted, editedAt, deletedAt, authorName}` + `body: string | null`, `BoardFile.{scanStatus, isQuarantined}` + `storedName?` (server strips it). `MAX_CARD_BYTES` exported as a runtime constant for the FilesPanel quota gate.
- **`hooks.ts`** (commit `039830c`) — eight new hooks: `useUpdateNotes` (optimistic), `useDownloadFile` (Blob → hidden anchor click), `useEditComment` (special-cases `WINDOW_EXPIRED` / `NOT_AUTHOR` toasts), `useSoftDeleteComment` (optimistic `{body:null, isDeleted:true}`), `useArchiveCard` (special-cases `PROJECT_NAME_MISMATCH`), `useUnreadNotificationCount` (60-second `refetchInterval`, `enabled` prop for sidebar gating), `useMarkCardNotificationsRead`. All errors flow through `handleMutationError` after special-case dispatch.
- **`NotesEditor.tsx`** (commit `31aee7b`) — Tabs-based editor; `SANITIZE_SCHEMA` extends `defaultSchema` and explicitly drops `script`/`iframe`/`object`/`embed`. Save flow: `useUpdateNotes` then switch to Preview. Footer shows last-edited metadata.
- **`FilesPanel.tsx`** (commit `8c48634`) — storage gauge + click/drag-drop upload zone + file list with download/delete actions. Pre-flight quota gate; upload-error mapping for 413/415/422/503; quarantined files render a badge and disable download.
- **`CardDetailModal.tsx`** (commit `22d25df`) — full rewrite of the modal's body. Stacked sections for Notes, Files, Comments (with edit pencil within the 10-minute window, soft-delete via `window.confirm`, `[deleted]` placeholder, `(edited)` suffix). Modal widened to `max-w-2xl` with `max-h-[90vh] overflow-y-auto`.
