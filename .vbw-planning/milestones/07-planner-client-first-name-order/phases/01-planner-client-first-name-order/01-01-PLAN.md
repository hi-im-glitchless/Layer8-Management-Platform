<objective>
Reverse the name order on the Planner (`/board`) so the CLIENT name reads first and the PROJECT
name second, on both Planner surfaces — the Kanban card (`KanbanCard.tsx`) and the card detail
modal (`CardDetailModal.tsx`) — with the visual emphasis following the position: client takes the
`text-lg font-semibold` headline treatment, project drops to `text-sm font-bold`.

The client is optional, so the headline must never be blank: use the chained-OR fallback and
suppress the second line when the headline already fell back to the project name. The pin
indicator moves with row 1. The "client name carries no inline colour" legibility guard from
Phase 10 stands and must survive in both code and tests. Frontend-only; no backend, schema, API,
or permission surface is involved.
</objective>
