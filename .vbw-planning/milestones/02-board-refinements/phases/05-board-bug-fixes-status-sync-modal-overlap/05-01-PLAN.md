<objective>
Fix Bug 1: a project's status edited on the Schedule does not propagate to the board (planner). Resolve all three contributing causes so the symptom fully clears: (a) PRIMARY — backend `upsertByKey` is create-only and drops status changes on existing projects; (b) the KanbanCard memo comparator omits `project.status` so the card won't re-render even after a correct cache refresh; (c) `useUpdateAssignment` does not invalidate `['board','cards']`. After this plan, editing a status on the schedule updates Project.status in the DB, invalidates the board cache, and the board card re-renders with the new status. No Prisma migration (status/color already exist). Schedule isolation preserved — only Project is written; the board read path stays read-only against Assignment/TeamMember/Absence/Holiday.
</objective>
