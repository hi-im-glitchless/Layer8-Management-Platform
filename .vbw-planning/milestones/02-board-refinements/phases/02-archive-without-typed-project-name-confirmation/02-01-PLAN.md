<objective>
Remove the type-the-exact-project-name gate from the admin archive flow end to end —
UI dialog input + backend confirmProjectName requirement — while keeping a lightweight
Archive/Cancel confirm dialog (archive hard-deletes files). Drop confirmProjectName from
the contract entirely (route body, service signature, frontend api/hook), and remove
PROJECT_NAME_MISMATCH from ArchiveErrorCode. Backend, its coupled isolation test, and the
coupled frontend changes are grouped so each commit leaves tsc green. The empty-projectName
edge case is naturally resolved (nothing to match against).
NON-NEGOTIABLE: preserve the SCHEDULE-ISOLATION INVARIANT — keep the read-only
project:{select:{name:true}} join (still used for the audit projectName) and its JSDoc;
no writes to Assignment/TeamMember/Absence/Holiday. No Prisma migration.
</objective>
