<objective>
Add a backend-only "out today" capability: a service function that returns the active team members who have an Absence on a given date (defaulting to today, UTC), exposed via GET /api/schedule/absences/out-today with authz consistent with existing schedule reads. Reuse the existing Absence model and absenceService — no new model, no migration, no frontend (the dashboard widget is Phase 02). The response must be widget-friendly: a flat, name-resolved list so Phase 02 needs no client-side resolution.
</objective>

- Normalise the target date to UTC midnight: `const d = targetDate ?? new Date(); const iso = d.toISOString().slice(0,10); const dayStart = new Date(`${iso}T00:00:00.000Z`); const nextDay = new Date(dayStart.getTime() + 86400000);`
