<objective>
Flip the project-notes editor on the planner card detail modal to render Preview -> Edit and
open on the Preview tab, without changing the client-notes page editor. The Edit/Preview tabs
live in the single shared component `frontend/src/components/NotesEditor.tsx`, so the flip must
be prop-driven: add an optional `previewFirst?: boolean` (default `false` = today's behavior).
Only `CardDetailModal` opts in; `ClientNotesModal` stays Edit-first / Edit-default. Edit stays
fully functional, save-on-success still lands on Preview in both modes. Frontend-only, no
backend changes. Keep `SANITIZE_SCHEMA` and the exported `NotesPreview` byte-for-byte unchanged.
</objective>
