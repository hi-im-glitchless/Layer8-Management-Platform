<objective>
Make ALL client-selection dropdowns list clients case- & accent-insensitively alphabetical (PT-PT aware) and provide client-side search. Do this by extracting the behavior once into a shared, generic, prop-driven ClientCombobox (Popover + Input + button-list, no new deps) backed by a shared sortClientsByName helper, then adopting it at both unique sites: the schedule ClientSelect (AssignmentModal, 2 instances — already has search, needs sort + dedupe of logic) and the board "All clients" filter (BoardFilters — a Radix Select that needs search added + sort). Sentinels ("No client" / "All clients") stay pinned; color swatch preserved where available. Client-side only — no backend/Prisma changes.
</objective>
